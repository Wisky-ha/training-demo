# 模型训练可视化平台——前端需求文档

**文档版本：** v1.1  
**文档状态：** 需求已确认，可进入设计与开发  
**适用范围：** 内部演示版

---

## 1. 前端目标

建设一个流程化模型训练工作台，用步骤条展示：

```text
选择模型类型 → 上传数据 → 数据预处理 → 数据集划分 → 模型训练 → 模型评估 → 保存与发布
```

每个步骤均可交互，并展示当前状态、操作结果和错误信息。

本版本支持三类模型：

- 电力负荷预测
- 冷热负荷预测
- 综合能耗预测

本版本为内部演示版，进度条使用阶段型演示进度，不要求展示真实训练百分比。

---

## 2. 前端公共规则

### 2.1 脚本

预处理脚本和训练脚本均为 Python 脚本，上传后进入全局共享脚本库。

前端通过下拉框选择脚本，脚本选项应显示：

- 脚本名称
- 脚本版本
- 脚本类型
- 适用模型类型
- 上传时间
- 启用状态

只展示与当前模型类型兼容且已启用的脚本。

### 2.2 数据字段

训练 CSV 默认按以下规则识别：

```text
第 1 列：时间列
第 2 列至倒数第 2 列：特征 X
最后 1 列：目标 y
```

预测输入不携带 `y`，必须携带时间列和训练时的全部特征列。

字段按名称校验，不要求预测输入字段顺序与训练数据一致。

### 2.3 数据划分

前端只展示划分结果，不提供比例编辑：

```text
按时间顺序：前 80% 为训练集，后 20% 为测试集
```

### 2.4 模型版本

每种模型类型都有系统提供的 `v0-baseline`。

模型发布后，当前生产版本出现异常时自动切换到最近健康版本，首页持续展示告警，直到新模型成功发布。

MCP 未指定版本时，默认使用该类型当前有效的最新已发布健康版本。

## 3. 页面和功能

## 3.1 首页

### 页面内容

首页展示三类模型卡片，每张卡片包含：

- 模型类型名称
- 当前有效版本
- 最近训练时间
- 当前模型状态
- 当前生产模型是否异常
- 自动回滚后的备份版本
- 开始训练按钮
- 查看版本按钮

### 告警展示

模型异常时，卡片展示明显告警，例如：

```text
模型 v3 异常，当前已自动切换至备份版本 v2
```

告警在新模型成功发布前不能隐藏或自动消失。

### 状态展示

支持展示：

- 未训练
- 训练中
- 待发布
- 已发布
- 已下线
- 异常
- 训练失败

---

## 3.2 选择模型类型

新建训练任务时提供三个选项：

- 电力负荷预测
- 冷热负荷预测
- 综合能耗预测

选择后加载：

- 当前有效模型信息
- 可用预处理脚本
- 可用训练脚本
- 历史版本
- 当前告警状态

未选择模型类型时，不允许进入数据上传步骤。

---

## 3.3 CSV 数据上传

### 上传交互

- 支持文件选择。
- 支持拖拽上传。
- 仅允许选择 CSV 文件。
- 展示上传中状态。
- 展示解析成功状态。
- 解析失败时展示具体错误。
- 文件为空或格式不正确时禁止继续。

### 上传成功后的展示

展示：

- 全量表头。
- 每一列的字段角色。
- 数据总行数。
- 数据总列数。
- 前若干行样例。
- 时间列解析结果。
- 数值列识别结果。
- 缺失值统计。

角色展示为：

```text
第一列：时间列
中间列：特征列
最后一列：目标列
```

本版本不提供拖拽调整字段角色功能，字段角色以系统默认规则为准。

---

## 3.4 数据预处理

### 页面操作

用户可以：

1. 从全局下拉框选择已有预处理脚本。
2. 上传新的 Python 预处理脚本。
3. 选择“跳过预处理”。

预处理脚本下拉框需要支持脚本名称和版本展示。

### 跳过预处理

选择跳过后：

- 显示“未使用预处理”。
- 不执行上传的预处理脚本。
- 允许直接进入数据集划分。
- 后续训练和预测均直接使用原始特征数据。

### 执行状态

展示阶段型演示进度：

```text
等待执行 → 数据读取 → 执行预处理 → 结果校验 → 完成
```

同时展示：

- 执行日志
- 处理前后行数
- 处理后字段
- 失败原因

不显示不真实的“训练完成百分比”或“预处理完成百分比”。

### 接口提示

页面提供简要脚本规范：

```python
class Preprocessor:
    def fit(self, df, config):
        return self

    def transform(self, df, config):
        return df
```

并提示：训练阶段拟合，测试和预测阶段使用已保存的处理状态。

---

## 3.5 数据集划分

页面展示固定规则：

```text
按时间顺序排序
前 80%：训练集
后 20%：测试集
```

展示：

- 训练集行数
- 测试集行数
- 训练集时间范围
- 测试集时间范围
- 划分方式

不展示可编辑的比例输入框，不允许在前端修改 80%/20% 配置。

---

## 3.6 模型训练

### 页面操作

用户可以：

- 从全局脚本库选择训练脚本。
- 上传新的 Python 训练脚本。
- 查看训练脚本版本和适用类型。
- 点击开始训练。

页面展示当前训练配置：

- 模型类型
- 数据集名称
- 预处理脚本或“未使用预处理”
- 训练脚本和版本
- 数据划分摘要

### 训练状态

展示：

```text
准备数据 → 加载训练脚本 → 执行训练 → 保存模型 → 进入评估
```

状态包括：

- 等待执行
- 执行中
- 成功
- 失败

展示实时或轮询获取的：

- 当前阶段
- 日志
- 错误信息
- 任务开始和结束时间

训练失败后提供重新训练入口，且明确提示不会影响当前生产模型。

---

## 3.7 模型评估

### 指标

使用指标卡片展示：

- MAE
- RMSE
- MAPE
- R²

MAPE 遇到实际值为 0 时，展示有效计算样本数和说明。

### 模型对比

展示当前生产模型和本次新训练模型的对比表：

| 指标 | 当前生产模型 | 新训练模型 | 变化 |
|---|---:|---:|---:|
| MAE |  |  |  |
| RMSE |  |  |  |
| MAPE |  |  |  |
| R² |  |  |  |

### 图表

至少展示：

1. 测试集实际值与预测值对比折线图。
2. 预测误差折线图或误差分布图。
3. 两个模型的指标对比图。

图表要求：

- 横轴使用时间。
- 图例区分实际值和预测值。
- 支持鼠标悬停查看具体数值。
- 大数据量时图形允许前端抽样，但指标展示必须使用完整数据计算结果。

新模型不要求指标一定优于基线，前端只展示差异，不自动替用户决定是否发布。

---

## 3.8 模型保存和发布

保存与发布页面展示：

- 模型类型
- 新模型版本
- 训练脚本及版本
- 预处理脚本及版本，或跳过状态
- 输入字段规范
- 数据划分规则
- 评估指标
- 与当前生产模型的对比

操作按钮：

- 保存模型
- 发布模型
- 返回修改

发布必须弹出二次确认，并提示：

```text
发布后该版本将成为当前有效模型，原生产版本将保留为回滚版本。
```

发布成功后显示当前有效版本和原备份版本。

---

## 3.9 模型版本管理

版本列表展示：

- 版本号
- 创建时间
- 训练脚本
- 预处理脚本
- MAE、RMSE、MAPE、R²
- 发布状态
- 异常状态
- 是否当前有效版本
- 是否可回滚

支持：

- 查看版本详情
- 发布待发布版本
- 下线版本
- 手动回滚
- 查看告警和回滚记录

---

## 3.10 MCP 服务说明

页面提供：

- MCP 服务地址
- `predict` 工具说明
- `mark_model_abnormal` 工具说明
- 必填和可选参数说明
- 请求示例
- 成功返回示例
- 错误码说明
- 各模型类型默认版本

需要明确标注：`model_version` 省略时，系统自动选择当前有效最新已发布健康版本。

## 4. 前端接口依赖

| 方法 | 路径 | 前端用途 |
|---|---|---|
| `GET` | `/api/model-types` | 首页模型卡片和类型选择 |
| `POST` | `/api/datasets/upload` | 上传并解析 CSV |
| `GET` | `/api/scripts` | 加载全局脚本下拉框 |
| `POST` | `/api/scripts/upload` | 上传预处理或训练脚本 |
| `POST` | `/api/training-jobs` | 创建训练任务 |
| `GET` | `/api/training-jobs/{id}` | 查询任务状态和阶段 |
| `GET` | `/api/training-jobs/{id}/logs` | 查询训练日志 |
| `GET` | `/api/training-jobs/{id}/evaluation` | 获取评估结果和图表数据 |
| `POST` | `/api/models/{id}/publish` | 发布模型 |
| `GET` | `/api/models` | 查询版本列表 |
| `GET` | `/api/models/{id}` | 查询版本详情 |
| `POST` | `/api/models/{id}/rollback` | 手动回滚 |
| `GET` | `/api/alerts` | 查询告警 |

---

## 5. 前端验收标准

- 能选择三类模型类型。
- 能上传 CSV 并展示全量表头。
- 能识别并展示时间列、特征列和目标列。
- 能展示行数、列数、样例数据和缺失值信息。
- 能从全局下拉框选择预处理脚本。
- 能上传预处理脚本并在后续任务中选择。
- 能跳过预处理并进入下一步。
- 跳过预处理后页面状态明确显示“未使用预处理”。
- 能从全局下拉框选择训练脚本。
- 能上传训练脚本并在后续任务中选择。
- 能展示预处理和训练阶段状态、日志和演示进度。
- 能展示实际值与预测值图表。
- 能展示 MAE、RMSE、MAPE、R²。
- 能展示新模型和当前生产模型的对比。
- 能确认发布新模型。
- 首页能展示异常告警和回滚后的版本。
- 能查看模型版本详情。
- 能查看 MCP 调用说明。
